## Como usar

1. Execute clasp push e recarregue o /dev.
2. Na Base de conhecimento, use **Simplificar guias** para atualizar as versões originais já importadas. Textos com edições próprias não são sobrescritos; imagens e publicação são preservadas. Novas importações já usam a revisão atual.
3. Descompacte o ZIP e selecione os quatro PNGs em **Enviar imagens em lote**.
4. Confira as legendas e envie. As imagens entram em Como fazer, antes dos passos. Não repita o upload dos itens concluídos.

Use a variante v2 do KB-0028: ela não desenha comunicação direta entre banco e navegador. A organização real deve ser confirmada com o responsável pelo ambiente.

Prompts: [prompts.json](prompts.json) e [revisão do KB-0028](KB-0028-revisao.prompt.md). A variante inicial é histórica e não integra o ZIP.
